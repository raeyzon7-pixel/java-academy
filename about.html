About Java Academy

I'm Shiv, I'm in Grade 11, and I made Java Academy as a review site for the Unit 1 Java stuff in ICS3U. It's for a class assignment where we had to explain each concept and show how it's used.

What's on the site

  • Ten lessons, in the order we did them in class. Each one has an explanation, examples with their output, common mistakes, a practice task with a solution, and a recap.
  • Practice questions for every lesson. I wrote these for the site, so they're not questions from the real test.
  • Mr. Lauder's class reminders on the home page: "Do not suffer in silence", "The key to success is consistency", and START, STOP, KEEP GOING for for loops.

Extra stuff

Anything marked Extra, like the other primitive types, && and ||, or the newer switch syntax, goes past what we need for the unit. You can skip it.

Are the outputs real?

Yes. Every example, mistake and solution was run with Java (JDK 25) by a test script in the project, and the output on each page is what Java actually printed. The quiz answers that depend on code were checked the same way. IntelliJ might word some error messages a little differently.

How this site was made

I made this site with help from an AI assistant (Claude), which wrote a lot of the code for the site. I made most of the content myself, including the practice questions, lessons, and examples. I published it with a GitHub repository.
