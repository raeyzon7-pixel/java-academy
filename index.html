Mr. Lauder's Class Reminders

Three things from class that are worth remembering for every lesson. Try filling in the blanks before you look.

Reminder 1

“Do not suffer in ______.”

Reveal the answer

Silence.

If you've been stuck on the same error for a while, ask someone. A friend or the teacher can usually spot a missing semicolon or a = that should be == way faster than you can by staring at it.

Reminder 2

“The key to success is ______.”

Reveal the answer

Consistency.

Doing a bit of Java most days works better than cramming the night before. Each lesson builds on the last one, so it's a lot easier to keep up than to catch up.

Reminder 3: for loops

START, STOP, KEEP GOING

for (int i = 0; i < 5; i++)
  • START: int i = 0 makes the counter, once, at the beginning.
  • STOP: i < 5. The loop continues while this is true and stops when it becomes false.
  • KEEP GOING: i++ increases i after each iteration.

So i goes 0, 1, 2, 3, 4, which is five times. At 5, STOP is false. Lesson 8 goes through it step by step.

How I'd use this site

  1. Guess the output first. Cover the output under an example and figure out what it prints before you look.
  2. Type the code yourself. Changing one thing at a time in IntelliJ helps way more than just reading it.
  3. Try the practice task before opening the solution. Being stuck for a few minutes is normal. If you're stuck for way longer, ask someone.
  4. Finish with the practice questions. Every answer tells you why it's right, and why the other options are wrong.

Test yourself. There are practice questions for every lesson: guess the output, trace loops, find the error, and write short programs.
