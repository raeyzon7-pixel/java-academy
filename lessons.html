Running the examples in IntelliJ

Every example here is a full program you can run. It's better to type it out than copy and paste, because you'll notice more.

  1. Open your project in IntelliJ, or make a new one with File > New > Project and pick Java.
  2. Right-click the src folder, go to New > Java Class, and type the class name from above the example (like Greeting). It has to match the name after public class exactly, capitals included.
  3. Type the code. Red underlines are syntax errors. Hover over them to see what's wrong.
  4. Click the green arrow next to main to run it.
  5. If it uses Scanner, click in the Run window at the bottom, type your answer, and press Enter.
  6. If it never stops (an infinite loop), click the red square to stop it.

All the outputs on this site came from actually running the code with Java (JDK 25) using the project's test script. IntelliJ might word error messages a bit differently.
