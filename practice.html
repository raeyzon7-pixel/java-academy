START, STOP, KEEP GOING: name the three parts of this loop and say how many times it runs.

for (int i = 1; i <= 3; i++)
Reveal the answer

START: int i = 1   STOP: i <= 3   KEEP GOING: i++

It runs with i = 1, 2 and 3, so 3 times. Once i is 4, 4 <= 3 is false and it stops.
